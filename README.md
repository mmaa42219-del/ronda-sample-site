# Brightside Studio (sample site)

A small sample marketing site created by [ronda](https://useronda.com) so you can try editing a web app
from your AI assistant without bringing your own. It has a home page with a hero and features, a pricing page,
and a header with a mobile menu.

Ask your assistant to change something (a headline, a colour, a new section) and ronda shows it in a live preview.

```bash
npm install
npm run dev   # http://localhost:3000
npm run build
```
